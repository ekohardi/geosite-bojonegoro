# 🧭 Geopark Kedung Lantung — Bojonegoro

> **Geo-site G-05 · Bojonegoro, Jawa Timur, Indonesia**  
> Jejak air, batu, dan waktu yang membentuk kisah bumi di tepian hutan Bojonegoro.

🌐 **Live Website:** [https://geosite-bojonegoro.vercel.app/](https://geosite-bojonegoro.vercel.app/)

---

## 📌 Tentang Proyek

Website resmi / landing page untuk **Geosite Kedung Lantung (G-05)**, salah satu warisan geologi penting di Geopark Bojonegoro. Situs ini memadukan keindahan alam bentang batuan dan aliran sungai dengan edukasi ilmiah geodiversitas bagi wisatawan, pelajar, dan peneliti.

### ✨ Fitur Utama

- **Hero Panorama:** Tampilan visual megah Kedung Lantung dengan identitas resmi kode geosite `G-05`.
- **Eksplorasi Warisan Geologi:** Rangkuman nilai ilmiah, edukasi, dan geodiversitas bentang alam.
- **Galeri Momen Lapangan:** Showcase visual resolusi tinggi aliran air dan formasi batuan alami.
- **Narasi Interaktif (Audio):** Tombol narasi suara interaktif bahasa Indonesia untuk pengalaman pengunjung yang lebih mendalam.
- **Desain Responsif & Cepat:** Desain ramah perangkat seluler dengan navigasi menu dinamis dan performa tinggi berbasis Turbopack.

## 🚀 Menjalankan Secara Lokal

1. **Clone repositori:**
   ```bash
   git clone https://github.com/ekohardi/geosite-bojonegoro.git
   cd geosite-bojonegoro
   ```

2. **Instal dependensi:**
   ```bash
   pnpm install
   # atau
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   pnpm dev
   # atau
   npm run dev
   ```

4. **Buka di peramban:**
   Akses [http://localhost:3000](http://localhost:3000)

5. **Build untuk produksi:**
   ```bash
   pnpm build
   pnpm start
   ```
